# Path-Scoped Rules — индекс правил

Каждый файл правила объявляет glob в `paths:`-frontmatter и подгружается, когда клиент читает или правит совпадающие файлы. Правило без `paths:` грузится безусловно.

Новое правило: одна узкая тема, `paths:` на каталог/паттерн, до ~150 строк. Индекс ведётся здесь, дублировать список в `AGENTS.md` не нужно.
